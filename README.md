# charithareddymr.github.io

My personal site: writing and projects on AI security, cloud incident response and ML for intrusion detection.

Live at **https://charithareddymr.github.io**

Plain static HTML and CSS, no build step:

```
index.html        home page: writing + things I've made
projects.html     all projects, numbered
posts/            one HTML page per article
assets/site.css   shared styles (light and dark mode)
```

To add an article, copy an existing file in `posts/`, change the text, and add an entry to the Writing list in `index.html`. GitHub Pages republishes on every push.
